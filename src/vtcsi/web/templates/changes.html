Bước tiếp theo

Commit xong chưa phải là phát sóng. Còn ba bước, theo đúng thứ tự:

vtcsi validate                 # cau hinh co hop le khong
vtcsi preflight <dump>.xml     # bang nao can tang version
vtcsi build --out build        # sinh XML cho tsp

Nếu preflight báo đổi ngầm thì dừng lại: nội dung đã đổi mà version giữ nguyên, đầu thu sẽ không đọc lại bảng.
